# VS Code 扩展 · 自动升版打包安装

参考工作日记 `jnl-3C91E7A2`。

## 脚本（`abs/sh/`）

| 脚本 | 职责 |
|------|------|
| `pack-background.sh` | 升版 → `npm install` → `compile` → `vsce package`（含 dependencies）→ `dist/background-<version>.vsix` |
| `install-background.sh` | 选 vsix → `cursor`/`code --install-extension` → 清旧扩展目录 |

## VS Code / Cursor Tasks

| Task | 命令 |
|------|------|
| `background: pack` | `pack-background.sh`（默认 patch +1） |
| `background: pack (no-bump)` | 按当前版本打包 |
| `background: install` | 安装已有 vsix（缺包则自动 pack） |
| `background: all` | `install --pack` 一条龙 |

## 要点

- 版本真源：`package.json` 的 `version`；产物名带版本，便于对账。
- 默认打包前 patch +1，不打 git tag。
- `--no-bump` / `--bump minor|major` 按需。
- 安装后只保留 `publisher.name-version` 当前目录，避免多版本共存。
